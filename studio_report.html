4. Reflective Summary on Algorithmic Optimization (200 Words)
During Activity 8, I explored foundational algorithmic paradigms in linear data structures, 2D matrix operations, string parsing, and hashing techniques in C.

Solving Diagonal Difference reinforced matrix indexing efficiency, achieving O(N) time complexity by accumulating primary (A[i][i]) and secondary (A[i][N-1-i]) diagonal elements in a single linear pass without auxiliary space (O(1)). In Dynamic Array, managing dynamic sequence vectors required implementing geometric array resizing via realloc, guaranteeing O(1) amortized insertion time per query while operating under O(N+Q) space. The Time Conversion challenge highlighted constant-time O(1) string parsing and conditional arithmetic logic to format 12-hour AM/PM representations into 24-hour military time without overhead. Compare the Triplets demonstrated constant O(1) element-wise comparison and score accumulation. Finally, Sparse Arrays highlighted the contrast between brute-force O(N × Q) string search and optimal hash map frequency mapping. By constructing a custom chaining hash table using the djb2 algorithm, query lookup efficiency was reduced to O(1) expected time (O(N+Q) total), avoiding redundant comparisons.

Overall, this activity deepened my practical expertise in selecting optimal data structures, managing heap dynamic memory in C safely, and balancing space-time trade-offs for scalable software engineering.
